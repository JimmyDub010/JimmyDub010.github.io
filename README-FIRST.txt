JIMMYDUB ACCESSIBLE GAMING & SOFTWARE WEBSITE
=============================================

This is a starter website made with plain HTML and a small stylesheet.
It is designed to work with keyboard navigation and screen readers.

FILES
-----
index.html                 Home page
projects.html              Project directory
projects/                  Individual project pages
support.html               Patreon / PayPal support information
updates.html               Development updates
contact.html               Contact and feedback
styles.css                 Basic site styling

BEFORE PUBLISHING
-----------------
1. Open support.html and replace the Patreon and PayPal.Me placeholder text
   with your public links. Do not publish until you have checked them.
2. Open contact.html and add the public contact method you want to use.
3. Open projects/112-operator.html and add the final download link after you
   upload the ZIP as a GitHub Release asset.
4. Check every project status and edit anything that is outdated.
5. Do not include private account screenshots or personal details.

PUBLISHING USING THE GITHUB WEBSITE (NO GITHUB DESKTOP REQUIRED)
----------------------------------------------------------------
1. Extract this ZIP on your computer.
2. Sign in to GitHub in your browser and open the repository used for your
   existing GitHub Pages site.
3. Download a backup of the existing site first if you want to keep it.
4. In the repository, use Add file -> Upload files.
5. Upload the contents of this folder (not the enclosing folder itself), so
   index.html and styles.css appear at the repository's publishing root.
   Keep the projects folder and its HTML files.
6. Review the changes and commit them to the branch your Pages site publishes
   from. If your repository publishes from the root of the main branch, commit
   there. If Pages uses a different branch or /docs folder, use that publishing
   location instead.
7. Wait for the Pages deployment to finish, then open the website and test
   every navigation link with NVDA.

IMPORTANT DOWNLOAD NOTE
-----------------------
The 112 Operator project page intentionally does not contain a fake download
link. Once the ZIP is uploaded to GitHub Releases, copy the actual asset URL
and replace the marked placeholder section in projects/112-operator.html.
