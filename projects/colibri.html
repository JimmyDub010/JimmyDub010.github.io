Colibri — Accessible AI Chat

An accessible AI chat application project, with a focus on making the interface usable with assistive technology.

Current status: In development; web research and page-reading capabilities are not yet complete.

Project goals

The goal is to build an AI chat application that is practical to use with a screen reader.

Current status

Development is ongoing. Web search and the ability to read and use web pages are among the capabilities that still need work.
